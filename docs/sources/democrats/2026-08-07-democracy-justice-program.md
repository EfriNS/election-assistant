## 1. גן את הזכויות האזרחיות והחברתיות בחוקי יסוד, וניתן להן מעמד עליון
נעגן בחוקי יסוד את זכויות האדם ואת הזכויות החברתיות – כולל הזכות לבריאות, לחינוך ולדיור – וניתן להן מעמד חוקתי עליון. נתקן גם את חוק הלאום כך שישקף באופן ברור את מחויבותה של ישראל להיות גם יהודית וגם דמוקרטית, ברוח מגילת העצמאות.

## 2. נדאג לכנסת חזקה שמסוגלת לפעול למען הציבור
נחוקק את חוק יסוד: החקיקה, שיסדיר את מעמדם של חוקי היסוד, יקבע כללים ברורים לחקיקתם ויעגן את הביקורת השיפוטית. נחזק את הכנסת כגוף שמפקח באמת על הממשלה, נחזק את ועדת האתיקה.

## 3. נבטיח את מחויבות הרשות המבצעת לציבור ולחוק
נקבע כללי אתיקה מחייבים לנבחרי ציבור ונגדיר סטנדרטים ברורים לשירות הציבורי. נעגן בחוק את עצמאות הייעוץ המשפטי והמעמד המחייב של חוות הדעת המשפטית, נבטיח הליכי מינוי מקצועיים ושקופים לתפקידים בכירים, ונגן על שומרי הסף מפני לחצים פוליטיים.

## 4. נבטל את חוקי ההפיכה המשטרית ונייעל את מערכת המשפט
נבטל את החקיקה שנועדה לפוליטיזציה של מערכת המשפט ולהחלשתה — ובראש ובראשונה את השינויים בוועדה לבחירת שופטים ואת הרחבת סמכויות בתי הדין הדתיים. נמנה שופטים, נקים בתי משפט לערעורים וניזום פתרונות לייעול ההליך המשפטי (פתרונות ייעודיים לפתרון סכסוכים, הנגשה דיגיטלית, פתרונות קהילתיים).

## 5. נחוקק את חוקי הגבלת הכהונה וננהל מלחמת חורמה בשחיתות
נגביל את כהונת ראש הממשלה לשמונה שנים, נקבע מנגנונים ברורים לנבצרות, ונעגן בחוק איסור כהונה תחת כתב אישום (שרים וראש ממשלה). נחמיר את הענישה על שחיתות שלטונית ונחזק את השקיפות בניהול כספי ציבור.
